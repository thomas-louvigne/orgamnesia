#+TITLE: Orgamnesia — installation

L'installation rapide, avec les paquets tout prêts, est dans le
[[file:../readme.fr.org][readme]]. Ce document couvre le reste. Une version anglaise est
dans [[file:install.org][install.org]].

* Depuis les sources

Fonctionne sur toutes les distributions Linux, sur macOS et sur Windows.

1. Installer les prérequis du système :
   - *Linux* : les [[https://v2.tauri.app/start/prerequisites/#linux][prérequis de Tauri]]
     (=webkit2gtk-4.1= et les outils de compilation) ;
   - *macOS* : les outils en ligne de commande de Xcode (=xcode-select --install=) ;
   - *Windows* : les [[https://v2.tauri.app/start/prerequisites/#windows][prérequis de Tauri]]
     (Microsoft C++ Build Tools), puis, depuis le dossier du dépôt cloné,
     =pwsh packaging/windows/fetch-tools.ps1=, qui télécharge le git et les
     dictionnaires fournis avec l'application.
2. Installer Rust via [[https://rustup.rs][rustup]], puis :

#+BEGIN_SRC sh
git clone https://github.com/thomas-louvigne/orgamnesia.git
cd orgamnesia
rustup target add wasm32-unknown-unknown
cargo install trunk tauri-cli --locked
cargo tauri build --bundles deb   # Linux ; ou --no-bundle
cargo tauri build --bundles app   # macOS ; ou dmg
cargo tauri build --bundles nsis  # Windows
#+END_SRC

Le résultat est produit dans =src-tauri/target/release/= :

- =bundle/deb/= : le paquet =.deb= ;
- =orgamnesia= : le programme seul, avec =--no-bundle= ;
- =bundle/macos/Orgamnesia.app= : à glisser dans =/Applications=. Compilée sur la
  machine, elle s'ouvre sans l'autorisation de quarantaine ;
- =bundle/nsis/Orgamnesia_<version>_x64-setup.exe= : l'installeur Windows.

* Arch Linux

** Paquet tout prêt

=sudo pacman -U orgamnesia-*-x86_64.pkg.tar.zst= installe aussi les dépendances.
Pour mettre à jour, refaire la même chose avec le fichier de la nouvelle version ;
pour désinstaller : =sudo pacman -R orgamnesia=.

** Dernière version de =main=

Pour avoir les nouveautés pas encore publiées. Le =PKGBUILD= de =packaging/arch=
compile la branche =main= et l'installe avec pacman. Il se lance *depuis ce
dossier*, qui contient aussi le fichier =.desktop= dont il a besoin :

#+BEGIN_SRC sh
sudo pacman -S --needed base-devel git webkit2gtk-4.1 \
  rust rust-wasm trunk cargo-tauri
git clone https://github.com/thomas-louvigne/orgamnesia.git
cd orgamnesia/packaging/arch
makepkg -si
#+END_SRC

La première ligne installe ce dont la compilation a besoin : le moteur web qui
dessine la fenêtre (=webkit2gtk-4.1=), le compilateur (=rust=), sa cible
WebAssembly pour l'interface (=rust-wasm=), et les outils qui compilent l'interface
(=trunk=) et l'application (=cargo-tauri=). =makepkg -si= compile ensuite (quelques
minutes) puis installe le paquet.

- *Mettre à jour* : dans =orgamnesia/packaging/arch=, =git pull= puis =makepkg -si=.
- *Avec rustup* : le paquet =rust= entre en conflit avec =rustup=. Garder =rustup=,
  retirer =rust= et =rust-wasm= de la première ligne, et lancer
  =rustup target add wasm32-unknown-unknown= avant =makepkg -si=.
- *Désinstaller* : =sudo pacman -R orgamnesia-git=.

* macOS

*Expérimental, pas testé* : l'application est compilée pour macOS, mais personne ne
l'a encore essayée sur un Mac ; elle peut ne pas fonctionner, ou pas entièrement.
Les retours (bugs, captures) sont les bienvenus.

** Premier lancement

Le =.dmg= contient une seule application pour les Mac Apple Silicon et Intel
(macOS 11 ou plus récent). Elle n'est pas signée par un compte développeur Apple :
au premier lancement, macOS refuse de l'ouvrir (« Orgamnesia est endommagé » ou
« développeur non identifié »). Pour l'autoriser, une seule fois :

#+BEGIN_SRC sh
xattr -dr com.apple.quarantine /Applications/Orgamnesia.app
#+END_SRC

ou, sans terminal : la lancer une fois, puis /Réglages Système › Confidentialité et
sécurité/ › /Ouvrir quand même/.

** Particularités

- *Correcteur d'orthographe* : macOS n'a pas de dictionnaires Hunspell. Copier les
  fichiers =.aff= et =.dic= (par exemple =fr_FR.aff= et =fr_FR.dic=, ceux de
  [[https://extensions.libreoffice.org/][LibreOffice]]) dans =~/Library/Spelling/=,
  ou choisir leur dossier dans les préférences. Ceux de LibreOffice, s'il est
  installé, sont trouvés tout seuls.
- *Raccourcis* : dans le profil classique, Cmd fait ce que fait Ctrl (Cmd+S
  enregistre, Cmd+Z annule). Dans le profil Emacs, comme dans Emacs sur Mac, Ctrl
  reste celui d'Emacs, Option sert de Meta (Option+W est =M-w=, pas ∑) et Cmd garde
  les raccourcis habituels du Mac (Cmd+C, Cmd+V, Cmd+S, Cmd+Z…).
- *Extension org-bloom* : =org-bloom= et =pandoc= sont aussi cherchés dans les
  dossiers de Homebrew (=/opt/homebrew/bin=, =/usr/local/bin=).

* Windows

*Expérimental, pas testé* : l'installeur est compilé et le code vérifié pour
Windows, mais personne ne l'a encore essayé sur un ordinateur Windows ; il peut ne
pas fonctionner, ou pas entièrement. Les retours (bugs, captures) sont les
bienvenus.

** Installation

Double-cliquer sur =Orgamnesia_<version>_x64-setup.exe=, puis « Suivant ».
L'application s'installe pour l'utilisateur seul, sans droits d'administrateur, et
se désinstalle depuis /Paramètres › Applications/. Elle a besoin de WebView2, le
moteur web de Windows, présent sur Windows 10 et 11 à jour ; s'il manque,
l'installeur le télécharge.

L'installeur n'est pas signé : si Windows affiche « Windows a protégé votre
ordinateur », cliquer sur /Informations complémentaires/ puis /Exécuter quand même/.

** Git fourni avec l'application

Rien à installer : l'application apporte son git (MinGit, la version de Git for
Windows faite pour être embarquée) et Git Credential Manager. Si git est déjà
installé sur l'ordinateur, c'est lui qui est utilisé, avec ses réglages.

Au premier commit, l'application demande le nom et l'e-mail inscrits dans les
commits, une seule fois pour tous les projets.

** Se connecter à un dépôt distant

Les dépôts peuvent être n'importe où. Deux façons de s'y connecter :

- *Adresse https* (=https://…=), la plus simple. Au premier pull ou push, une
  fenêtre s'ouvre :
  - *GitHub, GitLab, Bitbucket* : connexion dans le navigateur, comme sur le site ;
  - *Codeberg, ou un autre serveur* (Forgejo, Gitea, serveur personnel…) : nom
    d'utilisateur et mot de passe. Avec la double authentification activée, le mot
    de passe est un /jeton d'accès/ : sur Codeberg, /Paramètres › Applications ›
    Générer un nouveau jeton/, avec l'accès en lecture et écriture aux dépôts.

  Les identifiants sont ensuite gardés par le gestionnaire d'identifiants de
  Windows : la fenêtre ne revient plus.
- *Adresse ssh* (=git@…=) : choisir la clé privée dans /Préférences › Extensions/.
  Pour en créer une, dans PowerShell : =ssh-keygen -t ed25519=, puis ajouter le
  contenu du fichier =.pub= à son compte (GitHub, GitLab, Codeberg :
  /Paramètres › Clés SSH/). Une clé protégée par une phrase de passe doit être
  chargée dans l'agent ssh de Windows.

** Particularités

- *Fins de ligne* : le git fourni garde les fins de ligne Unix des pages, comme
  Emacs, Linux et macOS les écrivent.
- *Correcteur d'orthographe* : les dictionnaires français et anglais sont fournis
  (ceux de LibreOffice). D'autres se choisissent dans les préférences.
- *Extension org-bloom* : elle n'est pas fournie ; à installer à part.
- *Réglages* : dans =%APPDATA%\com.orgamnesia.app\=.
