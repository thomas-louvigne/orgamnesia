#+TITLE: Orgamnesia — changelog

What changes in each version, newest first. The app shows these notes when a new
version is available; they are also the text of the versions published on GitHub.
The French version is in [[file:changelog.fr.org][changelog.fr.org]].

* 1.5.0
- New versions: on Arch Linux (AUR package), the new version window gives the command of your AUR helper to copy; the Flatpak app leaves its updates to Flathub and no longer looks for new versions.
- New versions: a new version available is also told on the empty editor.
- Shortcuts: the arrow keys are shown as arrows (←, →, ↑, ↓).
- New description: a lightweight Obsidian, second brain and personal wiki, for Markdown and/or Emacs Org-mode notes.

* 1.4.0
- Commands: type > in quick open (Ctrl+K) to list every action of the app with its shortcut; Enter runs the one chosen.
- Switch project from the keyboard: Ctrl+Alt+P (or C-x p p with the Emacs keys) opens the project menu; the arrows choose, Enter opens, Escape closes. When it opens, the rest of the window dims and the menu stands out.
- Projects: a project whose folder no longer exists is left out of the menu; it comes back with the folder.
- Did you know?: a frame, in the right column by default, gives a tip with the shortcut of your profile; › shows the next one. It can be hidden or moved in Settings > Display.
- Shortcuts: a button clicked with the mouse recalls its shortcut in the status bar, three times at most per action. Turned off in Settings > Shortcuts.
- The right-click menu of the pages shows the shortcut of New page.

* 1.3.0
- Graph (beta): an extension, off by default, offered on the first run and in Settings > Extensions. It draws the pages and their links in 3D in the main area (Ctrl+Shift+M, or C-c g with the Emacs keys). A click opens a page; dragging moves the graph, the right button turns around it, the wheel or the bar zooms, ▶ turns it on its own. Pages without links are in another colour.
- Graph: while it turns or moves, the names of the page shown and of the pages linked to it, either way, stay written.
- Graph: a Graph button, in the right column by default, opens or closes it. Shown only when the extension is on; it can be hidden or moved in Settings > Display.
- Settings: the hints give the shortcuts of your profile (Classic, Emacs or yours), no longer the Classic ones.

* 1.2.3
- Themes: a Themes tab in the settings chooses the colours of the app: Automatic (light or dark as the system is, following it), Night, Day, Fjord (dark blue-grey, after Nord), Paper (warm light) or Dracula.
- Your own themes: a theme is one CSS file in the themes folder of the settings. Duplicate copies a theme there to change it, Reload reads it again; the docs explain the colours to set.

* 1.2.2
- Search: a .* button searches with a regular expression, in the page and in the whole project; $1, ${name} in the replacement take the groups of the match. Accents then count, and an invalid expression says so.

* 1.2.1
- Emacs shortcuts: swap characters (Ctrl+T) and words (Alt+T), change the case of a word (Alt+U, Alt+L, Alt+C) or of the selection (Ctrl+X Ctrl+U, Ctrl+X Ctrl+L), delete spaces (Alt+\, Alt+Space), join lines (Alt+^), kill up to a character (Alt+Z), rewrap a paragraph (Alt+Q), select all (Ctrl+X H), redo (Ctrl+Shift+?).
- Emacs kill ring: it keeps the previous kills, and Alt+Y right after a yank goes back through them.
- Videos: Vimeo, Dailymotion, Twitch and PeerTube links are drawn as thumbnails, like YouTube's; a click plays the video in the app or opens it in the browser, as set in Settings > Links.
- Quick open: the names that start with the text typed come first, the list follows the arrows, and opening a page puts the keyboard in its text.
- New heading: cuts the line at the caret, what follows becoming the text of the new heading or item.
- Emojis: "Insert an emoji" in the editor's right-click menu on Linux, and a box in Settings > Shortcuts to turn off WebKit's shortcuts for its emoji picker.
- Settings: a Default button puts the current tab back to its defaults. An option missing from a settings file takes its default value.
- Fix: after an emoji in a page, editing commands (kills, yank, search, completion…) no longer act at the wrong place.
- The settings, the first run and git's commit, history, cloning and identity are shown in the main area, no longer in windows; a new remote and a new branch are asked in the git frame.
- Git: a pull or push refused by SSH asks for the key's passphrase in the git frame, then runs again. It stays in memory until the app closes and is never saved.
- Git: an icon in the git frame opens the history of the page shown (Ctrl+Shift+L, or C-x g l l with the Emacs keys).
- Git: the frame holds on two lines, the branch and the state above, Pull, Commit and Push below.
- Settings > About: the logo and the name in large, the links to the website, the documentation, the latest commit and the author.
- Correction: on Linux, the folder picker always shows the button creating a folder.

* 1.2.0
- Git: the branch is a list to switch to another branch, local or remote, or to create a new one.
- Git: commit and sync take only the project's folder, never the rest of a repository it is part of.
- First run: the git module and the to-do list are offered, or not.
- Safety: a link never opens a help file, an add-in, a disk image or a macOS launcher (.chm, .iso, .terminal…).
- Fix: hidden files (Emacs' .#Note.org locks, macOS' ._Note.md) no longer show as pages.
- Fix: renaming a page changing only the case works on macOS and Windows.
- Fix: page names refuse : * ? " < > |, which Windows can't take.
- Fix: the blank pages deleted on quitting go to the trash.
- Fix: undoing a project replacement keeps the pages not put back when a write fails.

* 1.1.0
- Fix: the build's tests pass on Windows.

* 1.0.0
- Markdown pages: .md files are pages alongside .org ones, with their headlines, folding, TODO keywords and checkboxes, tables, images, highlighting, YAML front matter (title and tags) and export. On the first run, the app asks the format of new pages and the shortcuts.
- Links: [[Page|text]], [[Page#Headline]] and [text](Page.md), each turned on or off for org-mode and for Markdown pages.
- Links to a headline or a target ([[Page::*Headline]], [[Page::target]]), and a preview of the page a link leads to.
- Export of a page as PDF or as a single HTML file, from its tab or the list of pages.
- Settings: a "Links" tab, and an "About" tab with the version.
- Fix: a page typed in while it is being saved is no longer marked saved before the disk holds it; pages and settings are written all or nothing.

* 0.21.1
- Windows: org-bloom is not available; its setting is greyed out.
- Fix: on Windows, pages are written with the line endings they have in the git repository, whatever git's core.autocrlf setting.

* 0.21.0 (2026-10-29)
- Windows (experimental, not tested yet): an installer, without administrator rights, with git included.
- Signing in to git repositories over https in a window (browser for GitHub, GitLab, Bitbucket; user name and token for Codeberg and other servers).
- On the first commit, the app asks the name and email to write in the commits.
- Updates: a new version is offered with what is new in it, to install, postpone or skip.
- Fix: the "~" folder offered to clone a repository is the home folder.

* 0.20.0 (2026-10-29)
- Git: history of a page (right-click on a tab or a page), with its changes and restoring a version.
- Git: the commit window lets you choose the files and see what changed.
- Git: automatic sync (commit, pull, push) every N minutes, and on quitting if you wish.
- Git: create a repository, add a remote, clone a repository as a new project.
- Git: a ↑ marks the pages not pushed yet; a click on "in conflict" opens the files in conflict, counted as resolved once fixed.
- Git: pull puts uncommitted changes aside and replays your commits on a diverged history.
- YouTube videos: a link alone on its line shows the thumbnail; Logseq's {{video}} macro is marked, and replaced by a link in one click.
- "Import a file…" in the right-click menu: any file is copied into assets/ and linked from the page.
- Ctrl+click on a web link opens the browser, on a link to a file its application.

* 0.19.0 (2026-10-26)
- Settings as text: the settings and shortcuts open in the editor, checked as you type, with a history.
- One "Open or create a folder of notes…", which can also create the folder.
- A folder of notes without assets/: the app offers to create it, or to open the Logseq project around it.

* 0.18.0 (2026-10-26)
- Emacs profile closer to org-mode: Tab folds lists, blocks and drawers; windows to insert a link or a date; moving from cell to cell in tables.
- Alt+Up / Alt+Down moves a headline with all its content.
