#+TITLE: Orgamnesia — changelog

What changes in each version, newest first. The app shows these notes when a new
version is available; they are also the text of the versions published on GitHub.
The French version is in [[file:changelog.fr.org][changelog.fr.org]].

* 1.9.0
- Agenda, as in Emacs: Ctrl+Alt+A (C-c a in Emacs) shows the week day by day: scheduled and due headlines, dated notes and list items, the pages named after a date. A late schedule or a coming deadline shows on today. On a line: =t= the next TODO state, =s= / =d= its dates, Shift+arrows a day later or earlier, =f= / =b= the next or previous week, Enter opens the page.
- Schedule and deadline: C-c C-s / C-c C-d (Emacs) ask for a date, typed as =2026-12-01=, =+3d=, =tomorrow=, =monday=, =14:00=; =-= removes it.
- Repeaters (=+1w=, =++1w=, =.+1w=): a repeated headline marked done moves on to its next date. A headline done gets =CLOSED: [date]=.
- TODO list: filtered by state, by tags, dated or undated.
- Quick capture writes the day and time as a date (=<2026-11-24 Tue 14:05>=): its notes show in the agenda.
- Dates coloured in the page: the date, the day and the time each in its colour; =SCHEDULED:=, =DEADLINE:=, =CLOSED:= dimmed.
- Themes: =--h1= … =--h6= colour the headlines and =--ts-date=, =--ts-day=, =--ts-time= the dates, apart from the rest of the app.
- All of it in the terminal too.

* 1.8.6
- Typing =[= on a selection makes it a link: =[[selection]]=.
- The "keyboard quit" shortcut (Ctrl+G in Emacs) also drops a selection made with Shift or the mouse.
- Find and replace in the page: Replace and Replace all work again.
- Every =#+KEYWORD:= line (=#+DATE:=, =#+AUTHOR:=…) is coloured as =#+TITLE:= is.
- A new version is offered before a settings file found wrong at start.
- Terminal: no shortcut written in the code any more, only yours: Ctrl+J, Ctrl+C, Ctrl+N/P and Ctrl+G do what your shortcuts say (a Ctrl+Shift shortcut works from Ctrl alone, which most terminals send). In the window too, the completion follows your shortcuts.

* 1.8.5
- Folders: pages go in folders and subfolders of =pages/=, named by their path in links (=[[Games/Dragon]]=). The pages list becomes a foldable tree, in alphabetical order, the journal in a folder of its own. Right click or commands to make a folder, move a page into it, rename or delete a folder; the links follow.
- Page templates, as in Obsidian: the files of the =templates/= folder (configurable), with ={{title}}=, ={{date}}=, ={{time}}=, applied from quick open (type "template"). A Templates tab in the settings, and four suggested templates: meeting, person, reading, project.
- Quick capture: Ctrl+Alt+C (C-c c in Emacs) opens beside the page the day's page (or Inbox) on a new note; the same shortcut closes it.
- Tab names too long keep only their last folders (…/Quests/Dragon).
- All of it in the terminal too, and in "Did you know?".
- A page changed on disk by another program (Syncthing, another editor) while it is being edited is no longer overwritten: the app asks which text to keep. The terminal now notices these changes too.
- =settings.yaml= explains each setting in a comment above it.
- Terminal: delete a page and bring it back from the trash (commands "delete page", "trash", "empty trash"), undo the last replacement in the project; a link to a headline (=[[Page::*Title]]=) opens the page on it.
- Terminal: the commit lists the changed files to tick, with their changes in colour; the history of a page shows what each commit changed, and puts an old version back.
- Renaming a folder of many pages is much faster; a page whose links can't be updated no longer stops a rename halfway.
- Git: when git fails, the commit window no longer shows a page as wholly added.

* 1.8.4
- Zen mode: the text in the middle of the screen, at a reading width.

* 1.8.3
- "A click on a link follows it" (Settings > Links, off by default): a plain click follows a link, as Ctrl+click does. In the terminal too.
- Keyboard: the arrows, Space and +/- turn and zoom the graph as soon as it opens (they needed a click on it first); a new page, the page of the day, a random page and the page a link leads to take the cursor, to type in them straight away.
- A demo video in the readme.
- Inside: what the app does with projects, pages, git and the configuration is now its own crate (backend), shared by the window and the terminal.

* 1.8.2
- Zen mode: F11 (or Ctrl+Alt+Z, C-c z in Emacs) leaves only the page, full screen, without columns, tabs nor bars; a discreet line says how to leave it. In the terminal too.
- Random page: Ctrl+Alt+R (C-c r in Emacs), or the command of quick open, opens a page picked at random.
- Tables: Enter in a cell goes to the cell below, as org-mode does; with no row below, a new row is added. Tab and Enter no longer put the cursor a few characters too far left in a table under a headline.
- "Did you know?" in the terminal too, with new tips: random page, zen mode, the terminal version.
- Right click in the page: bold, italic, underline, strikethrough and quote. The editing commands are in quick open after =>=. The terminal version also opens with -nw, --tui or -t, and Ctrl+←/→ move by word there.
- A CLAUDE.md template (docs/CLAUDE.template.md) to put in a notes folder, so that an AI agent understands the pages, links, tags and TODOs.

* 1.8.1
- Code checks fixed (the build failed them); nothing changes in use.

* 1.8.0
- Terminal version (beta): orgamnesia --nox [folder] opens the project in the terminal, without a window. The list of pages filters as you type, pages are edited right there, highlighted as in the window, with the same shortcuts (classic, Emacs or custom profiles) and the same editing code: region, kill and yank, folding, tables, TODO states, emphasis, dates, links, find and replace, quick open, split screen, git, projects. F1 lists the shortcuts; F2 renames the page; F4, F5, F8 and F9 open the TODO headlines, the tags, the backlinks and the pages not created yet (new shortcuts, to change at will, which in the window open the title's renaming and give the focus to the frames). The window's frames (pages, backlinks, tags, TODO, pages not created, project, git) are in columns on each side, laid out as in the window, and F10 goes to the list of the pages. Names complete as in the window (links, headlines, tags). The session comes back on start, the git state shows at the bottom. The mouse places the cursor, Ctrl+click follows a link, the pages column can be resized. What doesn't work there yet is said in the documentation and in the settings files.
- The settings are now YAML (settings.yaml, keybindings/*.yaml), which takes comments. On the first start, the JSON files of older versions are converted; when the conversion kept the same settings, the app offers to delete the old files (they stay in the settings history).
- The settings file says, after each one, those that do nothing in the terminal version and why; each keybinding profile lists the shortcuts a terminal doesn't pass on.
- The "preference" project highlights YAML and its comments, and checks the files as you type as before (line and column of the error).

* 1.7.0
- Journal: the pages of the days are created in a journals/ folder, next to pages/, instead of among the other pages. Its name is changed in Settings > Extensions; a posts/ or daily/ folder already there is taken automatically. Existing dated pages don't move.
- Excalidraw: a drawing exported with its scene (.excalidraw.svg or .excalidraw.png) is shown in the page like an image, and stays editable in Excalidraw. Turned off in Settings > Display, under the images.
- Completion in Markdown links: after [text]( the files of the pages are offered, written encoded (My%20page.md), and the link is closed with ). After [[Page# the headlines of the page are offered. When those link syntaxes are read (Settings > Links).
- Accepting a completion is a single edit: one Ctrl+Z undoes it.
- Documentation: a project is the equivalent of an Obsidian vault.

* 1.6.2
- Live preview (Settings > Display, off by default): the markup (*, /, **, the brackets and target of the links, the stars of the headlines) fades away, and comes back on the line of the cursor.
- Ligatures: the editor draws -> and => as arrows, != as ≠… On by default, they are turned off in Settings > Display.

* 1.6.1
- Windows: the build no longer fails on a code check.

* 1.6.0
- Journal: an extension, off by default (Settings > Extensions). Ctrl+Shift+J (or C-c j with the Emacs keys), or the quick open command, opens today's page, named by its date, and creates it the first time.
- Back / forward arrows around the page title, as in a browser: ← goes back to the file opened before, → forward to the next one; each shows only when there is a file that way, and its tooltip gives the shortcut (Alt+← / Alt+→). Hidden in Settings > Display.
- Electric mode: typing * / or _ on selected text makes it bold, italic or underlined in org-mode; in Markdown, * or _ makes it italic, * twice bold. Turned off in Settings > Editing.
- Links: the mouse pointer becomes a hand over a link, a #tag or a :tag:.
- Display: an option brings out the text of [[target][text]] links: the text in bold, the target dimmed and underlined. The colours are theme variables (--link-target, --link-text, --link-text-weight).
- Settings: the frames around the editor have their own tab, Frames.
- Git: the Pull button is greyed out when there is nothing to pull.
- Tabs: with auto-save, the dot of unsaved changes no longer flickers on each keystroke.
- Editor: the highlighting, caret and spelling marks stay lined up with the text after a split or a redraw.

* 1.5.0
- New versions: on Arch Linux (AUR package), the new version window gives the command of your AUR helper to copy; the Flatpak app leaves its updates to Flathub and no longer looks for new versions.
- New versions: a new version available is also told on the empty editor.
- Shortcuts: the arrow keys are shown as arrows (←, →, ↑, ↓).
- New description: a lightweight Obsidian, second brain and personal wiki, for Markdown and/or Emacs Org-mode notes.

* 1.4.0
- Commands: type > in quick open (Ctrl+K) to list every action of the app with its shortcut; Enter runs the one chosen.
- Switch project from the keyboard: Ctrl+Alt+P (or C-x p p with the Emacs keys) opens the project menu; the arrows choose, Enter opens, Escape closes. When it opens, the rest of the window dims and the menu stands out.
- Projects: a project whose folder no longer exists is left out of the menu; it comes back with the folder.
- Did you know?: a frame, in the right column by default, gives a tip with the shortcut of your profile; › shows the next one. It can be hidden or moved in Settings > Display.
- Shortcuts: a button clicked with the mouse recalls its shortcut in the status bar, three times at most per action. Turned off in Settings > Shortcuts.
- The right-click menu of the pages shows the shortcut of New page.

* 1.3.0
- Graph (beta): an extension, off by default, offered on the first run and in Settings > Extensions. It draws the pages and their links in 3D in the main area (Ctrl+Shift+M, or C-c g with the Emacs keys). A click opens a page; dragging moves the graph, the right button turns around it, the wheel or the bar zooms, ▶ turns it on its own. Pages without links are in another colour.
- Graph: while it turns or moves, the names of the page shown and of the pages linked to it, either way, stay written.
- Graph: a Graph button, in the right column by default, opens or closes it. Shown only when the extension is on; it can be hidden or moved in Settings > Display.
- Settings: the hints give the shortcuts of your profile (Classic, Emacs or yours), no longer the Classic ones.

* 1.2.3
- Themes: a Themes tab in the settings chooses the colours of the app: Automatic (light or dark as the system is, following it), Night, Day, Fjord (dark blue-grey, after Nord), Paper (warm light) or Dracula.
- Your own themes: a theme is one CSS file in the themes folder of the settings. Duplicate copies a theme there to change it, Reload reads it again; the docs explain the colours to set.

* 1.2.2
- Search: a .* button searches with a regular expression, in the page and in the whole project; $1, ${name} in the replacement take the groups of the match. Accents then count, and an invalid expression says so.

* 1.2.1
- Emacs shortcuts: swap characters (Ctrl+T) and words (Alt+T), change the case of a word (Alt+U, Alt+L, Alt+C) or of the selection (Ctrl+X Ctrl+U, Ctrl+X Ctrl+L), delete spaces (Alt+\, Alt+Space), join lines (Alt+^), kill up to a character (Alt+Z), rewrap a paragraph (Alt+Q), select all (Ctrl+X H), redo (Ctrl+Shift+?).
- Emacs kill ring: it keeps the previous kills, and Alt+Y right after a yank goes back through them.
- Videos: Vimeo, Dailymotion, Twitch and PeerTube links are drawn as thumbnails, like YouTube's; a click plays the video in the app or opens it in the browser, as set in Settings > Links.
- Quick open: the names that start with the text typed come first, the list follows the arrows, and opening a page puts the keyboard in its text.
- New heading: cuts the line at the caret, what follows becoming the text of the new heading or item.
- Emojis: "Insert an emoji" in the editor's right-click menu on Linux, and a box in Settings > Shortcuts to turn off WebKit's shortcuts for its emoji picker.
- Settings: a Default button puts the current tab back to its defaults. An option missing from a settings file takes its default value.
- Fix: after an emoji in a page, editing commands (kills, yank, search, completion…) no longer act at the wrong place.
- The settings, the first run and git's commit, history, cloning and identity are shown in the main area, no longer in windows; a new remote and a new branch are asked in the git frame.
- Git: a pull or push refused by SSH asks for the key's passphrase in the git frame, then runs again. It stays in memory until the app closes and is never saved.
- Git: an icon in the git frame opens the history of the page shown (Ctrl+Shift+L, or C-x g l l with the Emacs keys).
- Git: the frame holds on two lines, the branch and the state above, Pull, Commit and Push below.
- Settings > About: the logo and the name in large, the links to the website, the documentation, the latest commit and the author.
- Correction: on Linux, the folder picker always shows the button creating a folder.

* 1.0.0
- Markdown pages: .md files are pages alongside .org ones, with their headlines, folding, TODO keywords and checkboxes, tables, images, highlighting, YAML front matter (title and tags) and export. On the first run, the app asks the format of new pages and the shortcuts.
- Links: [[Page|text]], [[Page#Headline]] and [text](Page.md), each turned on or off for org-mode and for Markdown pages.
- Links to a headline or a target ([[Page::*Headline]], [[Page::target]]), and a preview of the page a link leads to.
- Export of a page as PDF or as a single HTML file, from its tab or the list of pages.
- Settings: a "Links" tab, and an "About" tab with the version.
- Fix: a page typed in while it is being saved is no longer marked saved before the disk holds it; pages and settings are written all or nothing.
