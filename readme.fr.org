* Pourquoi Orgamnesia

- *Vos notes restent de simples fichiers =.org=* dans le dossier de votre choix :
  pas de base de données, pas de format propriétaire. Emacs, git ou un outil de
  synchro peuvent les lire en parallèle.
- *Des pages liées*, comme dans un wiki : liens =[[Page]]=, liens entrants, tags.
- *Léger* : une application de bureau native écrite en Rust, rapide à lancer.

* Fonctionnalités

- *Ouvrir ou créer un dossier de notes* dans la même fenêtre : un nouveau dossier
  reçoit =pages/= et =assets/=, prêt à écrire ; un dossier de fichiers =.org= existant s'ouvre tel quel.
- *Liens et tags* : =[[Page]]=, =#mots-clés= et =:tags:=, avec complétion ;
  renommer une page réécrit les liens qui y mènent.
- *Cadres* autour de l'éditeur : pages, liens entrants, tags, à faire, git…, placés
  à votre guise.
- *Ouverture rapide* (Ctrl+K) et *recherche et remplacement dans le projet*
  (Ctrl+Maj+F).
- *Éditeur org-mode* : coloration, tableaux, états TODO, niveaux des titres, deux
  volets, raccourcis Emacs ou Classique.
- *Correcteur d'orthographe* : fautes soulignées, suggestions au clic droit,
  dictionnaire personnel (dictionnaires Hunspell).
- *Corbeille* avec annulation, *sauvegarde automatique*, pages modifiées par un
  autre programme rechargées.
- *Préférences en texte* : les fichiers de réglages et de raccourcis ouverts dans
  l'éditeur, vérifiés pendant la frappe, appliqués à chaud, avec historique.
- *Git* : état du projet, commit (choix des fichiers, aperçu des modifications),
  pull, push, historique d'une page, synchronisation automatique, clonage.
- *Extensions* : site web statique avec
  [[https://github.com/thomas-louvigne/org-bloom][org-bloom]].
- Interface en français et en anglais.

Toutes les fonctionnalités en détail : [[file:docs/fonctionnalites.org][docs/fonctionnalites.org]].

* Prise en main

1. Lancez Orgamnesia et *ouvrez ou créez un dossier de notes* : un nouveau dossier
   est préparé avec =pages/= et =assets/=, un dossier qui contient déjà des
   fichiers =.org= s'ouvre tel quel.
2. *Créez une page* avec le bouton =+= de la liste des pages.
3. Tapez =[[Autre page]]= pour faire un lien vers une autre page ; Ctrl+clic
   l'ouvre, et la crée au besoin.
4. Ctrl+K ouvre n'importe quelle page ; F1 liste tous les raccourcis.

* Installation

Téléchargez le fichier de votre système sur la
[[https://github.com/thomas-louvigne/orgamnesia/releases/latest][page des versions]] :

| Système                        | Fichier        | Installation                                     |
|--------------------------------+----------------+--------------------------------------------------|
| Debian, Ubuntu, Mint…          | =.deb=         | =sudo apt install ./Orgamnesia_*.deb=            |
| Arch Linux                     | =.pkg.tar.zst= | =sudo pacman -U orgamnesia-*.pkg.tar.zst=        |
| Tout Linux                     | =.AppImage=    | =chmod +x Orgamnesia_*.AppImage=, puis le lancer |
| macOS 11+ (expérimental)       | =.dmg=         | glisser Orgamnesia dans Applications             |
| Windows 10, 11 (expérimental)  | =-setup.exe=   | double-cliquer, puis « Suivant »                 |

*Les versions macOS et Windows sont expérimentales* : elles sont compilées
automatiquement, mais n'ont pas encore été testées sur un Mac ni sur un ordinateur
Windows. Elles peuvent ne pas fonctionner, ou pas entièrement. Linux est le système
sur lequel l'application est utilisée et testée. Les retours (bugs, captures) sont
les bienvenus dans les [[https://github.com/thomas-louvigne/orgamnesia/issues][issues]].

*macOS* : l'application n'est pas signée, donc macOS refuse de l'ouvrir la première
fois. Autorisez-la une fois avec
=xattr -dr com.apple.quarantine /Applications/Orgamnesia.app=, ou par
/Réglages Système › Confidentialité et sécurité › Ouvrir quand même/.

*Windows* : l'installation ne demande pas de droits d'administrateur, et git est
fourni avec l'application. Elle n'est pas signée : si Windows affiche « Windows a
protégé votre ordinateur », cliquez sur /Informations complémentaires/ puis
/Exécuter quand même/.

Compiler depuis les sources, la dernière version de =main= sur Arch, et les
particularités de macOS et de Windows (dictionnaires, touches, connexion aux
dépôts git) :
[[file:docs/installation.org][docs/installation.org]].

* Vos données

- Les pages : les fichiers =.org= du dossier du projet.
- Les réglages : =~/.config/com.orgamnesia.app/= sous Linux,
  =~/Library/Application Support/com.orgamnesia.app/= sous macOS,
  =%APPDATA%\com.orgamnesia.app\= sous Windows. Ils se modifient
  en texte depuis l'application, vérifiés pendant la frappe, avec un historique des
  versions valides (voir [[file:docs/fonctionnalites.org::*Préférences en texte][Préférences en texte]]).

* Développement

Application de bureau en Rust : Tauri v2 (backend, =src-tauri/=) et Leptos 0.7
(interface compilée en WebAssembly, =src/=) ; =core/= contient ce qu'ils partagent.

#+BEGIN_SRC sh
cargo tauri dev     # lancement avec rechargement à chaud
cargo test --lib    # tests (aussi dans src-tauri/ et core/)
#+END_SRC

Installer les outils : [[file:docs/installation.org][docs/installation.org]].

** Publier une version

1. Écrire les nouveautés pour les utilisateurs dans
   [[file:changelog.fr.org][changelog.fr.org]] et [[file:changelog.org][changelog.org]] :
   un titre =* X.Y.Z (date)=, puis des puces =- = en texte simple. Sans elles, la
   publication échoue.
2. Monter la version (les =Cargo.toml=, les =Cargo.lock=,
   =src-tauri/tauri.conf.json=, =packaging/arch-release/PKGBUILD=) et pousser sur
   =main= : la publication compile les paquets, les signe pour les mises à jour,
   les publie avec les notes, puis =latest.json=, que lisent les applications
   installées.

Les paquets sont signés avec la clé créée par =cargo tauri signer generate= : sa
moitié publique est dans =tauri.conf.json= (=plugins.updater.pubkey=), la privée et
son mot de passe dans les secrets =TAURI_SIGNING_PRIVATE_KEY= et
=TAURI_SIGNING_PRIVATE_KEY_PASSWORD= du dépôt. Gardez la clé privée : sans elle,
les applications installées ne peuvent plus être mises à jour.
