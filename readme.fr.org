* Fonctionnalités

- *Pages et liens* : liens =[[Page]]=, =#mots-clés= et =:tags:= org-mode, avec
  complétion pendant la frappe. Ctrl+clic ouvre une page (et la crée au besoin) ;
  renommer une page réécrit les liens qui y mènent.
- *Cadres autour de l'éditeur* : pages, liens entrants, tags (recherche à la syntaxe
  org : =a+b-c=, =a|b=), à faire, pages pas encore créées, git… chacun affiché ou
  non, dans la colonne de gauche ou de droite, dans l'ordre choisi.
- *Ouverture rapide* (Ctrl+K) : n'importe quelle page, onglet ouvert ou tag.
- *Recherche dans le projet* (Ctrl+Maj+F) : toutes les pages, et remplacement
  (Ctrl+Maj+H) occurrence par occurrence ou en bloc, annulable.
- *Éditeur* : coloration org-mode, titre de la page en haut, recherche et
  remplacement, sauvegarde automatique, deux volets, raccourcis Emacs ou Classique
  (configurables).
- *Niveau des titres* : Alt+Maj+→ / ← descendent ou remontent un titre d'un niveau,
  avec ses sous-titres, comme dans Emacs (voir [[file:docs/fonctionnalites.org#niveau-des-titres][Niveau des titres]]).
- *Tableaux* : dessinés comme de vrais tableaux ; Tab / Maj+Tab passent d'une cellule
  à l'autre et réalignent le tableau comme dans Emacs ; =|-= + Tab trace la ligne d'en-tête.
- *États TODO* sur les titres (=* TODO Titre=) : mis en valeur, et changés avec
  Maj+←/→ dans les raccourcis Emacs. Les états se règlent dans les préférences
  (=TODO DOING HANGUP | DONE=) ou par une ligne =#+TODO:= dans la page. Le cadre
  « À faire » rassemble les titres TODO de tout le projet.
- *Corbeille* : une page supprimée va dans le dossier =.trash= du projet ; « Annuler »
  dans la barre d'état la remet en place. Les préférences la vident, à la main ou
  automatiquement (durée et poids maximum réglables).
- *Extensions* : état git du projet, site web statique du projet avec
  [[https://github.com/thomas-louvigne/org-bloom][org-bloom]].
- Les pages modifiées par un autre programme (synchro, git…) sont rechargées.
  Français et anglais.

Le détail de toutes les fonctionnalités est dans [[file:docs/fonctionnalites.org][docs/fonctionnalites.org]].

* Installation (Linux)

** Debian, Ubuntu, Mint… et autres distributions

Télécharger le =.deb= (Debian, Ubuntu, Mint…) ou l'=.AppImage= (toutes distributions)
sur la [[https://github.com/thomas-louvigne/orgamnesia/releases/latest][page des versions]].

#+BEGIN_SRC sh
sudo apt install ./Orgamnesia_*.deb   # .deb
chmod +x Orgamnesia_*.AppImage        # .AppImage : le rendre exécutable,
./Orgamnesia_*.AppImage               # puis le lancer
#+END_SRC

** Arch Linux

*** Paquet tout prêt (le plus rapide)

Télécharger le fichier =orgamnesia-X.Y.Z-1-x86_64.pkg.tar.zst= sur la
[[https://github.com/thomas-louvigne/orgamnesia/releases/latest][page des versions]],
puis l'installer avec pacman, qui installe aussi les dépendances :

#+BEGIN_SRC sh
sudo pacman -U orgamnesia-*-x86_64.pkg.tar.zst
#+END_SRC

Orgamnesia apparaît ensuite dans le menu des applications, ou se lance avec
=orgamnesia=. Pour mettre à jour, refaire la même chose avec le fichier de la
nouvelle version ; pour désinstaller : =sudo pacman -R orgamnesia=.

*** Compiler la dernière version de =main=

Pour avoir les nouveautés pas encore publiées. Le =PKGBUILD= de =packaging/arch=
compile la branche =main= et l'installe avec pacman. Il se lance *depuis ce
dossier*, qui contient aussi le fichier =.desktop= dont il a besoin :

#+BEGIN_SRC sh
sudo pacman -S --needed base-devel git webkit2gtk-4.1 \
  rust rust-wasm trunk cargo-tauri
git clone https://github.com/thomas-louvigne/orgamnesia.git
cd orgamnesia/packaging/arch
makepkg -si
#+END_SRC

La première ligne installe ce dont la compilation a besoin ; s'il en manque un,
=makepkg= s'arrête dessus :

- =webkit2gtk-4.1= : le moteur web qui dessine la fenêtre ;
- =rust= : le compilateur ;
- =rust-wasm= : la cible WebAssembly, pour l'interface ;
- =trunk= : compile l'interface ;
- =cargo-tauri= : compile l'application.

=makepkg -si= compile ensuite (quelques minutes) puis installe le paquet. Orgamnesia
apparaît dans le menu des applications, ou se lance avec =orgamnesia=.

- *Mettre à jour* : dans =orgamnesia/packaging/arch=, =git pull= puis =makepkg -si=.
- *Avec rustup* : le paquet =rust= entre en conflit avec =rustup=. Garder =rustup=,
  retirer =rust= et =rust-wasm= de la première ligne, et lancer
  =rustup target add wasm32-unknown-unknown= avant =makepkg -si=.
- *Désinstaller* : =sudo pacman -R orgamnesia-git=.

** Depuis les sources (toutes distributions)

Installer les [[https://v2.tauri.app/start/prerequisites/#linux][prérequis de Tauri]]
et Rust (via [[https://rustup.rs][rustup]]), puis :

#+BEGIN_SRC sh
git clone https://github.com/thomas-louvigne/orgamnesia.git
cd orgamnesia
rustup target add wasm32-unknown-unknown
cargo install trunk tauri-cli --locked
cargo tauri build --bundles deb   # ou --no-bundle
#+END_SRC

Le =.deb= est produit dans =src-tauri/target/release/bundle/deb/= ; avec
=--no-bundle=, le programme seul est =src-tauri/target/release/orgamnesia=.

** Données

Les pages restent de simples fichiers =.org= dans le dossier choisi ; les réglages
sont dans =~/.config/com.orgamnesia.app/=
(=~/Library/Application Support/com.orgamnesia.app/= sur macOS).

* Installation (macOS)

*Pas encore testé sur un Mac* : l'application est compilée pour macOS, mais personne
ne l'a encore essayée. Les retours (bugs, captures) sont les bienvenus.

** Image disque

Télécharger le =.dmg= sur la
[[https://github.com/thomas-louvigne/orgamnesia/releases/latest][page des versions]]
(une seule application pour les Mac Apple Silicon et Intel, macOS 11 ou plus récent),
l'ouvrir et glisser Orgamnesia dans le dossier Applications.

L'application n'est pas signée par un compte développeur Apple : au premier lancement,
macOS refuse de l'ouvrir (« Orgamnesia est endommagé » ou « développeur non
identifié »). Pour l'autoriser, une seule fois :

#+BEGIN_SRC sh
xattr -dr com.apple.quarantine /Applications/Orgamnesia.app
#+END_SRC

ou, sans terminal : la lancer une fois, puis /Réglages Système › Confidentialité et
sécurité/ › /Ouvrir quand même/.

** Depuis les sources

Installer les outils en ligne de commande de Xcode (=xcode-select --install=) et Rust
(via [[https://rustup.rs][rustup]]), puis :

#+BEGIN_SRC sh
git clone https://github.com/thomas-louvigne/orgamnesia.git
cd orgamnesia
rustup target add wasm32-unknown-unknown
cargo install trunk tauri-cli --locked
cargo tauri build --bundles app   # ou dmg
#+END_SRC

L'application est produite dans =src-tauri/target/release/bundle/macos/Orgamnesia.app= :
la glisser dans =/Applications=. Compilée sur la machine, elle n'a pas besoin de
l'autorisation ci-dessus.

** Particularités

- *Correcteur d'orthographe* : macOS n'a pas de dictionnaires Hunspell. Copier les
  fichiers =.aff= et =.dic= (par exemple =fr_FR.aff= et =fr_FR.dic=, ceux de
  [[https://extensions.libreoffice.org/][LibreOffice]]) dans =~/Library/Spelling/=,
  ou choisir leur dossier dans les préférences. Ceux de LibreOffice, s'il est
  installé, sont trouvés tout seuls.
- *Raccourcis* : dans le profil classique, Cmd fait ce que fait Ctrl (Cmd+S
  enregistre, Cmd+Z annule). Dans le profil Emacs, comme dans Emacs sur Mac, Ctrl
  reste celui d'Emacs, Option sert de Meta (Option+W est =M-w=, pas ∑) et Cmd garde
  les raccourcis habituels du Mac (Cmd+C, Cmd+V, Cmd+S, Cmd+Z…).
- *Extension org-bloom* : =org-bloom= et =pandoc= sont aussi cherchés dans les
  dossiers de Homebrew (=/opt/homebrew/bin=, =/usr/local/bin=).

* Windows

Le support de Windows n'est pas prévu pour le moment.

* Développement

Application de bureau écrite en Rust : Tauri v2 (backend, =src-tauri/=) et Leptos 0.7
(interface compilée en WebAssembly, =src/=) ; =core/= contient ce qu'ils partagent.

#+BEGIN_SRC sh
cargo tauri dev     # lancement avec rechargement à chaud
cargo test --lib    # tests (aussi dans src-tauri/ et core/)
#+END_SRC
