#+TITLE: Orgamnesia

A lite Obsidian with an Emacs flavour: a personal wiki made of =org-mode= files,
with links between pages and backlinks. Desktop app written in Rust: Tauri v2 (backend) and
Leptos 0.7 (frontend, compiled to WebAssembly).

/[[file:readme.fr.org][🇫🇷 Version française]]/

#+BEGIN_QUOTE
*Beta version.* The project is under active development: expect bugs, features may
change, and you should keep a copy of your =.org= files.

*AI-generated code.* This application was coded with the help of Claude (Anthropic),
an AI. Review the code with the same critical eye as any other contribution.
#+END_QUOTE

* Features

** Projects
- A project is a folder of =.org= files (pages live in =pages/=).
- "Open folder" button and a selector to switch between projects.
- A default project can be set in the preferences.

** Pages and links
- =[[Page]]= and =[[Page][display text]]= links. Ctrl+click (or /Follow link/) opens the page, creating it if it doesn't exist.
- *Keywords*: =#idea= is a link to the page =idea= (option, on by default).
  Not keywords: =#+TITLE=, =# comment= and =a#b=.
  Dashes (=#my-tag=) are allowed as an option; unchecked, only letters, digits and =_= count, like in org-mode.
- *Org-mode tags*: =#+FILETAGS: :project:rust:= for the whole page, =* Title :urgent:= for a headline.
  A headline inherits the tags of the page and of its parent headlines, like in Emacs.
  A tag is a link: Ctrl+click opens (or creates) the page of the same name, whose backlinks list what carries the tag.
  Completion after =:= in a headline and in =#+FILETAGS:=. The /Tags/ tab of the right-hand panel lists every tag
  and allows searches in org syntax (=project+urgent-personal=, =a|b=).
- *Backlinks*: right-hand panel listing the pages that point to the open page.
- *Uncreated pages*: links that lead nowhere, sorted by number of uses
  (=target (3)=). Click: go where the link is used. Right-click: create the page or go to the link.
- Case-insensitive links (option, on by default).
- Sidebar: right-click to /rename/ or /delete/ a page (the file is really removed).
- Renaming a page rewrites every link pointing to it, =[[…]]= and =#…= alike (option, on by default).

** Editing
- org-mode highlighting: headings, =TODO=/=DONE=, bold, italic, quotes, tables, links.
- Autosave on every keystroke (option, on by default).
- "Electric" mode: with text selected, typing =( ) [ ] " '= wraps the selection.
- Editor split in two panes (vertical or horizontal), each with its own header.

** Interface
- The sidebar and right panel widths can be resized by dragging their border;
  so can the height of the "Uncreated pages" block. Sizes are remembered.
- Resizable preferences window; its size is remembered.
- French and English.

* Keybindings

Shortcuts are configurable in *Settings → Shortcuts*: two presets (*Classic* and
*Emacs*) plus your own custom profiles, with key sequences and conflict detection.

* Installation

Orgamnesia runs on Linux. There are no prebuilt downloads yet: the app is
compiled on your machine, which takes a few minutes the first time.

** Debian, Ubuntu, Linux Mint, Pop!_OS…

1. Install the build tools and system libraries:

   #+BEGIN_SRC sh
   sudo apt update
   sudo apt install build-essential curl wget file git pkg-config libssl-dev \
     libwebkit2gtk-4.1-dev libxdo-dev libayatana-appindicator3-dev librsvg2-dev
   #+END_SRC

2. Install Rust (skip if =cargo= is already available), then the web target,
   Trunk and the Tauri CLI:

   #+BEGIN_SRC sh
   curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
   source "$HOME/.cargo/env"
   rustup target add wasm32-unknown-unknown
   cargo install trunk tauri-cli --locked
   #+END_SRC

3. Download the sources, build the =.deb= package and install it:

   #+BEGIN_SRC sh
   git clone https://github.com/thomas-louvigne/orgamnesia.git
   cd orgamnesia
   cargo tauri build --bundles deb
   sudo apt install ./src-tauri/target/release/bundle/deb/Orgamnesia_*_amd64.deb
   #+END_SRC

Orgamnesia now appears in your applications menu. To uninstall:
=sudo apt remove orgamnesia=.

** Arch Linux, Manjaro, EndeavourOS…

A =PKGBUILD= is provided. =makepkg= installs the build dependencies itself
(=-s=) and then installs the package with pacman (=-i=):

#+BEGIN_SRC sh
sudo pacman -S --needed base-devel git
git clone https://github.com/thomas-louvigne/orgamnesia.git
cd orgamnesia/packaging/arch
makepkg -si
#+END_SRC

The package (=orgamnesia-git=) builds the latest version of =main=; run
=makepkg -si= again in the same folder to update. To uninstall:
=sudo pacman -R orgamnesia-git=.

** Other Linux distributions

Install the [[https://v2.tauri.app/start/prerequisites/#linux][Tauri prerequisites]]
for your distribution (mainly WebKitGTK 4.1), Rust, then build as in step 2 and 3
of the Debian section but without packaging:

#+BEGIN_SRC sh
cargo tauri build --no-bundle
install -Dm755 src-tauri/target/release/orgamnesia ~/.local/bin/orgamnesia
install -Dm644 src-tauri/icons/icon.png ~/.local/share/icons/hicolor/512x512/apps/orgamnesia.png
install -Dm644 packaging/arch/orgamnesia.desktop ~/.local/share/applications/orgamnesia.desktop
#+END_SRC

Make sure =~/.local/bin= is in your =PATH=. To uninstall, delete these three files.

** Your data

Your wiki pages are plain =.org= files in the folder you choose in the app; they
are never touched by uninstalling. Settings live in =~/.config/com.orgamnesia.app/=.
