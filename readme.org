#+TITLE: Orgamnesia

A personal wiki made of =org-mode= files, with links between pages, backlinks and
Emacs-style keybindings. Desktop app written in Rust: Tauri v2 (backend) and
Leptos 0.7 (frontend, compiled to WebAssembly).

/[[file:readme.fr.org][Version française]]/

#+BEGIN_QUOTE
*Beta version.* The project is under active development: expect bugs, features may
change, and you should keep a copy of your =.org= files.

* Features

** Projects
- A project is a folder of =.org= files (pages live in =pages/=).
- "Open folder" button and a selector to switch between projects.
- A default project can be set in the preferences.

** Pages and links
- =[[Page]]= and =[[Page][display text]]= links. Ctrl+click (or /Follow link/) opens the page, creating it if it doesn't exist.
- *Keywords*: =#idea= is a link to the page =idea= (option, on by default).
  Not keywords: =#+TITLE=, =# comment= and =a#b=.
- *Backlinks*: right-hand panel listing the pages that point to the open page.
- *Uncreated pages*: links that lead nowhere, sorted by number of uses
  (=target (3)=). Click: go where the link is used. Right-click: create the page or go to the link.
- Case-insensitive links (option, on by default).
- Sidebar: right-click to /rename/ or /delete/ a page (the file is really removed).
- Renaming a page rewrites every link pointing to it, =[[…]]= and =#…= alike (option, on by default).

** Editing
- org-mode highlighting: headings, =TODO=/=DONE=, bold, italic, quotes, tables, links.
- Autosave on every keystroke (option, on by default).
- "Electric" mode: with text selected, typing =( ) [ ] " '= wraps the selection.
- Emacs-style selection marker (=C-SPC=).
- Editor split in two, like Emacs windows (see below).

** Interface
- The sidebar and right panel widths can be resized by dragging their border;
  so can the height of the "Uncreated pages" block. Sizes are remembered.
- Resizable preferences window; its size is remembered.
- French and English.

* Keybindings

Everything is configurable in *Settings → Shortcuts*.

- Two presets: *Classic* and *Emacs*.
- As soon as you change a shortcut, a *Custom* profile is created; you can have several
  and rename them. All profiles have the same fields (some stay empty).
- Key sequences (=C-x C-s=), with Ctrl, Shift, Alt.
- Two actions cannot share the same combination: a conflict is shown in red, with an alert,
  and prevents saving.
- *Apply* button (doesn't close the window), greyed out when there is nothing to apply.

* Installation and running

Requirements: Rust (with the =wasm32-unknown-unknown= target), [[https://trunkrs.dev][Trunk]],
=cargo-tauri= and Tauri v2's system dependencies (WebKitGTK on Linux).

#+BEGIN_SRC sh
rustup target add wasm32-unknown-unknown
cargo install trunk tauri-cli --locked

cargo tauri dev      # development, hot reload
cargo tauri build    # application bundle
#+END_SRC

Tests:

#+BEGIN_SRC sh
cargo test --lib           # frontend (pure functions)
cd src-tauri && cargo test # backend (parser, link index, settings)
#+END_SRC

* Code layout

| Path                      | Role                                                        |
|---------------------------+-------------------------------------------------------------|
| =src/=                    | Leptos frontend: =app.rs=, =state.rs=, =components/=         |
| =src/keybindings.rs=      | Profiles, key sequences, shortcut resolution                 |
| =src/motion.rs=           | Emacs-style motions and link lookup (pure functions)         |
| =src/highlight.rs=        | Editor syntax highlighting                                   |
| =src-tauri/src/commands/= | Tauri commands: projects, files, renaming, links             |
| =src-tauri/src/parser/=   | org-mode parser, link extraction and rewriting               |
| =src-tauri/src/index/=    | Backlink index                                               |
| =public/css/app.css=      | Styles                                                       |

Settings live in =~/.config/com.orgamnesia.app/= (=settings.json=, =keybindings.json=).
Panel sizes are kept in the window's =localStorage=.
