with links between pages and backlinks.

* Features

- *Pages and links*: =[[Page]]= links, =#keywords= and org-mode =:tags:=, with
  completion while typing. Ctrl+click opens a page (and creates it if needed);
  renaming a page rewrites the links to it.
- *Right-hand panel*: backlinks, tags (search in org syntax: =a+b-c=, =a|b=) and
  pages not created yet.
- *Quick open* (Ctrl+K): any page, open tab or tag.
- *Editor*: org-mode highlighting, page title on top, find & replace, autosave,
  split in two panes, Emacs or Classic keybindings (configurable).
- *Tables*: drawn as real tables; Tab / Shift+Tab move between cells and realign
  the table as in Emacs; =|-= + Tab draws the header rule.
- *TODO states* on headlines (=* TODO Title=): highlighted, and stepped through
  with Shift+←/→ in the Emacs keybindings. The states are set in the settings
  (=TODO DOING HANGUP | DONE=) or by a =#+TODO:= line in the page. The "To do"
  frame gathers the TODO headlines of the whole project.
- *Trash*: a deleted page goes to the project's =.trash= folder; "Undo" in the
  status bar brings it back. The settings empty it, by hand or automatically
  (maximum age and size can be set).
- *Extensions*: git state of the project, export to a website with
  =logseq-site-builder=.
- Pages changed by another program (sync, git…) are reloaded. French and English.

Every feature is described in detail, with screenshots, in [[file:docs/features.org][docs/features.org]].

* Installation (Linux)

Download the =.deb= (Debian, Ubuntu, Mint…) or the =.AppImage= (other distributions)
from the [[https://github.com/thomas-louvigne/orgamnesia/releases/latest][Releases page]].
On Arch Linux, a =PKGBUILD= is in =packaging/arch= (=makepkg -si=).

To build from the sources, install the
[[https://v2.tauri.app/start/prerequisites/#linux][Tauri prerequisites]] and Rust, then:

#+BEGIN_SRC sh
rustup target add wasm32-unknown-unknown
cargo install trunk tauri-cli --locked
cargo tauri build --bundles deb   # or --no-bundle
#+END_SRC

Your pages stay plain =.org= files in the folder you choose; settings live in
=~/.config/com.orgamnesia.app/=.

* Development

Desktop app written in Rust: Tauri v2 (backend, =src-tauri/=) and Leptos 0.7
(interface compiled to WebAssembly, =src/=); =core/= holds what both share.

#+BEGIN_SRC sh
cargo tauri dev     # run with hot reload
cargo test --lib    # tests (also in src-tauri/ and core/)
#+END_SRC
