* Why Orgamnesia

- *Your notes stay plain =.org= files* in a folder you choose: no database, no
  proprietary format. Emacs, git or any sync tool can read them alongside.
- *Linked pages*, as in a wiki: =[[Page]]= links, backlinks, tags.
- *Light*: a native desktop app written in Rust, quick to start.

* Features

- *Open or create a folder of notes* in the same dialog: a new folder gets =pages/=
  and =assets/=, ready to write in; an existing folder of =.org= files opens as is.
- *Links and tags*: =[[Page]]=, =#keywords= and =:tags:=, with completion;
  renaming a page rewrites the links to it.
- *Frames* around the editor: pages, backlinks, tags, to do, git…, placed as you
  like.
- *Quick open* (Ctrl+K) and *project search and replace* (Ctrl+Shift+F).
- *Org-mode editor*: highlighting, tables, TODO states, headline levels, split view,
  Emacs or Classic keybindings.
- *Spell checker*: misspelled words underlined, suggestions on right click,
  your own dictionary (Hunspell dictionaries).
- *Trash* with undo, *autosave*, pages changed by another program reloaded.
- *Settings as text*: the settings and shortcut files opened in the editor,
  checked as you type, applied at once, with a history.
- *Extensions*: git state, static website with
  [[https://github.com/thomas-louvigne/org-bloom][org-bloom]].
- French and English interface.

Every feature, with screenshots: [[file:docs/features.org][docs/features.org]].

* Getting started

1. Launch Orgamnesia and *open or create a folder of notes*: a new folder is set
   up with =pages/= and =assets/=, one that already holds =.org= files opens as is.
2. *Create a page* with the =+= button of the list of pages.
3. Type =[[Other page]]= to link to another page; Ctrl+click opens it, and creates
   it if needed.
4. Ctrl+K opens any page; F1 lists all the shortcuts.

* Installation

Download the file for your system from the
[[https://github.com/thomas-louvigne/orgamnesia/releases/latest][Releases page]]:

| System                  | File               | Install                                       |
|-------------------------+--------------------+-----------------------------------------------|
| Debian, Ubuntu, Mint…   | =.deb=             | =sudo apt install ./Orgamnesia_*.deb=         |
| Arch Linux              | =.pkg.tar.zst=     | =sudo pacman -U orgamnesia-*.pkg.tar.zst=     |
| Any Linux               | =.AppImage=        | =chmod +x Orgamnesia_*.AppImage=, then run it |
| macOS 11+ (not tested)  | =.dmg=             | drag Orgamnesia to Applications               |

*macOS*: the application is not signed, so macOS refuses to open it the first time.
Allow it once with =xattr -dr com.apple.quarantine /Applications/Orgamnesia.app=,
or /System Settings › Privacy & Security › Open Anyway/.

Windows is not supported for now.

Building from the sources, the latest =main= on Arch, and macOS particulars
(dictionaries, Cmd and Option keys): [[file:docs/install.org][docs/install.org]].

* Your data

- Pages: the =.org= files in the project folder.
- Settings: =~/.config/com.orgamnesia.app/= on Linux,
  =~/Library/Application Support/com.orgamnesia.app/= on macOS. They can be edited
  as text from the app, checked as you type, with a history of the valid versions
  (see [[file:docs/features.org::*Settings as text][Settings as text]]).

* Development

Rust desktop app: Tauri v2 (backend, =src-tauri/=) and Leptos 0.7 (interface
compiled to WebAssembly, =src/=); =core/= holds what both share.

#+BEGIN_SRC sh
cargo tauri dev     # run with hot reload
cargo test --lib    # tests (also in src-tauri/ and core/)
#+END_SRC

Setting up the tools: [[file:docs/install.org][docs/install.org]].
