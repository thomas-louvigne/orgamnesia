#+TITLE: Orgamnesia — nouveautés

Ce qui change à chaque version, la plus récente en premier. L'application montre ces
notes quand une nouvelle version est disponible ; elles sont aussi le texte des
versions publiées sur GitHub. La version anglaise est dans [[file:changelog.org][changelog.org]].

* 1.4.0
- Commandes : tapez > dans l'ouverture rapide (Ctrl+K) pour lister toutes les actions de l'application avec leur raccourci ; Entrée lance celle choisie.
- Changer de projet au clavier : Ctrl+Alt+P (ou C-x p p avec les raccourcis Emacs) ouvre le menu des projets ; les flèches choisissent, Entrée ouvre, Échap ferme. À l'ouverture, le reste de la fenêtre s'assombrit et le menu ressort.
- Projets : un projet dont le dossier n'existe plus n'apparaît plus dans le menu ; il revient si le dossier revient.
- Le saviez-vous ? : un cadre, dans la colonne droite par défaut, donne une astuce avec le raccourci de votre profil ; › passe à la suivante. On peut le masquer ou le déplacer dans Réglages > Affichage.
- Raccourcis : un bouton cliqué à la souris rappelle son raccourci dans la barre d'état, trois fois au plus par action. Se coupe dans Réglages > Raccourcis.
- Le menu du clic droit sur les pages montre le raccourci de Nouvelle page.

* 1.3.0
- Graphe (bêta) : une extension, désactivée par défaut, proposée au premier lancement et dans Réglages > Extensions. Elle dessine les pages et leurs liens en 3D dans la zone principale (Ctrl+Maj+M, ou C-c g avec les raccourcis Emacs). Un clic ouvre une page ; glisser déplace le graphe, le bouton droit tourne autour, la molette ou la barre zoome, ▶ le fait tourner tout seul. Les pages sans lien sont d'une autre couleur.
- Graphe : pendant qu'il tourne ou se déplace, les noms de la page affichée et des pages liées à elle, dans un sens ou dans l'autre, restent écrits.
- Graphe : un bouton Graphe, dans la colonne droite par défaut, l'ouvre ou le ferme. Il n'apparaît que si l'extension est activée ; on peut le masquer ou le déplacer dans Réglages > Affichage.
- Réglages : les aides donnent les raccourcis de votre profil (Classique, Emacs ou le vôtre), et non plus ceux du profil Classique.

* 1.2.3
- Thèmes : un onglet Thèmes dans les préférences choisit les couleurs de l'application : Automatique (clair ou sombre comme le système, en le suivant), Nuit, Jour, Fjord (gris-bleu sombre, d'après Nord), Papier (clair chaud) ou Dracula.
- Vos propres thèmes : un thème est un fichier CSS du dossier themes des réglages. Dupliquer y copie un thème pour le modifier, Recharger le relit ; la documentation explique les couleurs à donner.

* 1.2.2
- Recherche : un bouton .* cherche avec une expression régulière, dans la page comme dans tout le projet ; $1, ${nom} dans le remplacement reprennent les groupes trouvés. Les accents comptent alors, et une expression invalide est signalée.

* 1.2.1
- Raccourcis Emacs : inverser des caractères (Ctrl+T) et des mots (Alt+T), changer la casse d'un mot (Alt+U, Alt+L, Alt+C) ou de la sélection (Ctrl+X Ctrl+U, Ctrl+X Ctrl+L), supprimer des espaces (Alt+\, Alt+Espace), joindre des lignes (Alt+^), couper jusqu'à un caractère (Alt+Z), remettre un paragraphe à la largeur (Alt+Q), tout sélectionner (Ctrl+X H), rétablir (Ctrl+Maj+?).
- Kill ring d'Emacs : il garde les coupes précédentes, et Alt+Y juste après un collage remonte dans celles-ci.
- Vidéos : les liens Vimeo, Dailymotion, Twitch et PeerTube s'affichent en miniatures comme ceux de YouTube ; un clic lit la vidéo dans l'application ou l'ouvre dans le navigateur, selon Réglages > Liens.
- Ouverture rapide : les noms qui commencent par le texte tapé viennent d'abord, la liste suit les flèches, et ouvrir une page met le clavier dans son texte.
- Nouveau titre : coupe la ligne au curseur, la suite devenant le texte du nouveau titre ou élément.
- Emojis : « Insérer un emoji » dans le menu du clic droit de l'éditeur sous Linux, et une case dans Réglages > Raccourcis pour couper les raccourcis de WebKit vers son sélecteur d'emojis.
- Réglages : un bouton Par défaut remet l'onglet courant à ses valeurs d'origine. Une option absente d'un fichier de réglages prend sa valeur par défaut.
- Correction : après un emoji dans une page, les commandes d'édition (couper, coller, recherche, complétion…) n'agissent plus au mauvais endroit.
- Les préférences, le premier lancement et, pour git, le commit, l'historique, le clonage et l'identité s'affichent dans la zone principale, et non plus dans des fenêtres ; un nouveau dépôt distant et une nouvelle branche se demandent dans le cadre git.
- Git : un pull ou un push refusé par SSH demande la phrase de passe de la clé dans le cadre git, puis se relance. Elle reste en mémoire jusqu'à la fermeture de l'application et n'est jamais enregistrée.
- Git : une icône du cadre git ouvre l'historique de la page affichée (Ctrl+Maj+L, ou C-x g l l avec les raccourcis Emacs).
- Git : le cadre tient sur deux lignes, la branche et l'état au-dessus, Pull, Commit et Push en dessous.
- Préférences > À propos : le logo et le nom en grand, les liens vers le site, la documentation, le dernier commit et l'auteur.
- Correction : sous Linux, le sélecteur de dossiers montre toujours le bouton de création d'un dossier.

* 1.2.0
- Git : la branche est une liste pour passer à une autre branche, locale ou distante, ou en créer une nouvelle.
- Git : le commit et la synchronisation ne prennent que le dossier du projet, jamais le reste d'un dépôt dont il fait partie.
- Premier lancement : le module git et la liste des tâches sont proposés, ou non.
- Sécurité : un lien n'ouvre jamais un fichier d'aide, un complément, une image disque ou un lanceur macOS (.chm, .iso, .terminal…).
- Correction : les fichiers cachés (verrous .#Note.org d'Emacs, ._Note.md de macOS) n'apparaissent plus comme des pages.
- Correction : renommer une page en ne changeant que la casse marche sur macOS et Windows.
- Correction : les noms de pages refusent : * ? " < > |, que Windows n'accepte pas.
- Correction : les pages vides supprimées à la fermeture vont dans la corbeille.
- Correction : annuler un remplacement dans le projet garde les pages non remises quand une écriture échoue.

* 1.1.0
- Correction : les tests de la compilation passent sous Windows.

* 1.0.0
- Pages Markdown : les fichiers .md sont des pages à côté des .org, avec leurs titres, le pliage, les mots-clés TODO et les cases à cocher, les tableaux, les images, la coloration, l'en-tête YAML (titre et tags) et l'export. Au premier lancement, l'application demande le format des nouvelles pages et les raccourcis.
- Liens : [[Page|texte]], [[Page#Titre]] et [texte](Page.md), chacun activé ou non pour les pages org-mode et pour les pages Markdown.
- Liens vers un titre ou une cible ([[Page::*Titre]], [[Page::cible]]), et aperçu de la page vers laquelle mène un lien.
- Export d'une page en PDF ou en un seul fichier HTML, depuis son onglet ou la liste des pages.
- Préférences : un onglet « Liens », et un onglet « À propos » avec la version.
- Correction : une page modifiée pendant son enregistrement n'est plus marquée enregistrée avant que le disque la contienne ; pages et préférences sont écrites en entier ou pas du tout.

* 0.21.1
- Windows : org-bloom n'est pas disponible ; son réglage est grisé.
- Correction : sous Windows, les pages gardent les fins de ligne qu'elles ont dans le dépôt git, quel que soit le réglage core.autocrlf de git.

* 0.21.0 (2026-10-29)
- Windows (expérimental, pas encore testé) : un installeur, sans droits d'administrateur, avec git fourni.
- Connexion aux dépôts git en https par une fenêtre (navigateur pour GitHub, GitLab, Bitbucket ; identifiant et jeton pour Codeberg et les autres serveurs).
- Au premier commit, l'application demande le nom et l'e-mail à inscrire dans les commits.
- Mises à jour : une nouvelle version est proposée avec ses nouveautés, à installer, remettre à plus tard ou ignorer.
- Correction : le dossier « ~ » proposé pour cloner un dépôt est bien le dossier personnel.

* 0.20.0 (2026-10-29)
- Git : historique d'une page (clic droit sur un onglet ou une page), avec ses modifications et la restauration d'une version.
- Git : la fenêtre de commit permet de choisir les fichiers et de voir ce qui a changé.
- Git : synchronisation automatique (commit, pull, push) toutes les N minutes, et en quittant si on le souhaite.
- Git : créer un dépôt, ajouter un dépôt distant, cloner un dépôt comme nouveau projet.
- Git : une flèche ↑ marque les pages pas encore poussées ; un clic sur « en conflit » ouvre les fichiers en conflit, comptés résolus une fois corrigés.
- Git : le pull met de côté les modifications non commitées et rejoue vos commits sur un historique divergent.
- Vidéos YouTube : un lien seul sur sa ligne affiche la vignette ; la macro {{video}} de Logseq est signalée, et remplacée par un lien d'un clic.
- « Importer un fichier… » dans le clic droit : tout fichier est copié dans assets/ et lié depuis la page.
- Ctrl+clic sur un lien web ouvre le navigateur, sur un lien vers un fichier son application.

* 0.19.0 (2026-10-26)
- Préférences en texte : les réglages et les raccourcis s'ouvrent dans l'éditeur, vérifiés pendant la frappe, avec un historique.
- Un seul « Ouvrir ou créer un dossier de notes… », qui peut aussi créer le dossier.
- Un dossier de notes sans assets/ : l'application propose de le créer, ou d'ouvrir le projet Logseq autour.

* 0.18.0 (2026-10-26)
- Profil Emacs plus proche d'org-mode : Tab replie listes, blocs et tiroirs ; fenêtres pour insérer un lien ou une date ; déplacement de cellule en cellule dans les tableaux.
- Alt+Haut / Alt+Bas déplace un titre avec tout son contenu.
